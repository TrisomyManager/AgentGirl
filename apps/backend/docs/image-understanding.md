# 图片理解（5.2）

2026-10-20：参考应用支持一轮最多 3 张 JPEG/PNG/WebP，单张 5 MiB、合计 10 MiB、1600 万像素以内。浏览器可预览、移除及只发送图片；普通/SSE 聊天共享同一处理入口。

`shared_runtime/image_input.py` 在工作线程校验真实图片格式和像素，应用 EXIF 方向、缩放最长边至 1536、转成 JPEG 并移除元数据。仅接受 base64 data URI，后端不抓取外部链接。原图不会写入服务端文件或浏览器历史；前端最多保留最近 3 条消息的预览，刷新后显示图片数量。

`LLMClient.generate/generate_stream` 使用现有模型直传图片，支持 OpenAI 兼容（含方舟）及 Anthropic 原生内容块。未配置/不支持图片/上游失败均明确提示，错误中不透传可能回显图片的上游正文。未更换默认方舟模型。

图片回合固定由 Chat 处理，不执行工具或设备操作。图片文字被明确作为不可信资料。SQL 对话保留用户文字、助手回复及 `has_image` 元数据；本轮不运行长期事实提取，避免将图片推测当成用户事实。原始图片不参与后续回合，后续回顾只能依据文字记录；此项不宣称跨轮图像记忆或完整视觉内容审核。模型本身可能出错，不能用本回归推断泛化识别准确率。

验证：

- 校验、两种模型请求格式、普通/SSE 入口、工具短路、缺失模型、上游错误脱敏、SQL 不含图片原件等离线回归。
- 临时隔离数据库和独立合成用户下，实际 `doubao-seed-2-0-mini-260428` 经普通和 SSE 接口均正确描述左侧红色正方形、右侧蓝色圆形，SSE 文字与最终回复一致。
- 浏览器实际上传、纯图片发送、识别回复、刷新后数量收据、390px 布局通过；修复窄屏顶栏换行造成操作按钮被挤出的问题。报告在忽略目录 `output/qa/image-result.json`，截图 `output/playwright/image-chat-mobile.png`。
