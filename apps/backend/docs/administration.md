# 设置与管理（6.4）

Web 与 PC 的设置入口共用六个分类：我的设置、主动陪伴、模型服务、语音服务、扩展、运行状态。普通账号只显示前两项；服务级配置、扩展目录和运行状态由参考宿主校验管理员角色。本机无账号模式仍仅允许本机访问。

模型/语音页面继续使用已有的有效配置与测试接口，不回显保存的密钥；空输入保留同服务商密钥。切换账号、权限、分类或关闭抽屉时清掉输入的密钥，迟到的加载/保存/测试结果不能进入新页面。配置读取失败时禁用保存并提供重试，避免默认表单覆盖未知配置。语音试听离开页面即停止。

主动陪伴使用同一可复用表单接入设置与事项页，按当前用户保存时区、四类规则、免打扰、日上限和冷却；读取/保存失败保留明确提示，账号切换拒绝旧响应。管理员不能借此修改其他用户的私人偏好。

`GET /orchestrator/admin/overview` 只返回当前参考进程是否就绪、启用模块的启动检查、SQL 模式和访问模式，不包含凭据、连接地址、用户清单或对话。它表示启动情况，不是持续探测第三方数据库或模型的可用性；模型、语音分别有实际连接测试。

扩展页支持浏览随应用提供的本地包、查看已发现扩展的加载/回退状态，并在宿主明确开放后安装固定内置包。当前内置“文本小工具”；安装前确认，版本摘要校验，不覆盖已有名称，安装不授予权限。启用及用户范围继续由宿主私有配置决定。详见 [插件说明](../plugins/README.md)。开放第三方远程市场和在线执行授权没有纳入这一入口。

验证包括：管理员/普通账号 HTTP 权限，默认安装拒绝、包版本/路径/链接/覆盖/预授权冲突、反复取消后磁盘线程完成、安装后停用与宿主授权后的真实工具执行；前端旧账号响应、保存失败保留编辑、配置加载失败与密钥清理回归。实际隔离浏览器验证六个分类、方舟配置保存/真实连接、豆包配置保存/真实 TTS、陪伴保存后刷新、扩展安装停用/宿主授权后方舟规划器调用、普通账号隐藏管理页和 390px 显示。ASR 测试按钮只检查配置完整性，此轮没有重新录音验证 ASR。

干净来源构建的 wheel 已检查内置 manifest/代码与源码一致、排除测试与私有配置；从独立安装包启动宿主并实际浏览、安装、宿主授权和调用文本扩展通过。旧本机构建缓存可能包含历史测试模块，分发应从干净来源构建并检查 wheel 内容。
