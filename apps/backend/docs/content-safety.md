# 内容检查与发出顺序

2026-10-20，路线图 7.2。此版本增强规则过滤与入口覆盖，不是完整语义审核，也不提供不可绕过的保证。

## 已实现

- 裁决包含 general / self_harm / custom / unverified_contact。普通拒绝不再使用心理危机文案；明确自伤意图给予支持与即时安全建议。未核实的热线号码不会由默认输出规则放行。
- NFKC、大小写、空白与标点归一化覆盖简单拆词。预防、求助、恢复、拒绝语境可正常讨论；危险操作请求添加预防后缀仍会拒绝。输入和输出均限制为 16,000 字符。
- 普通对话先检查输出，再合成语音、生成动作、投递和记录。SSE 的模型、工具确定性回复与远程人格流均先通过有界检查，再发送 token 和安排 TTS。按句检查，单个无标点块最长 240 字；自定义 BLOCK 正则完整缓冲，防止未来后缀命中前泄露前缀。
- 输入拦截会短路模型与工具。任务入口同时检查初始请求、合并后的补充请求、规划结果和工具观察；检查异常时停止后续操作。主动陪伴候选被拦截时不推送无关拒绝。
- voice_layer 通过宿主注入检查端口，不反向导入编排器。cloud/local 在 ASR 后检查输入，在文字/PCM 发出前检查生成流；直接语音合成入口也检查文本。
- 原生 O2 的输入最终转写、完整 CHAT 文本与 TTS caption 均检查。CHAT 文字在完整检查后显示；默认规则可按已批准 caption 播放对应音频。未知或要求完整输出的宿主策略会等待完整 CHAT。无 caption 音频最多暂存 30 秒 PCM；音频结束后完整文字最多再等 2 秒。缺文字、超时或超限时停止并丢弃供应商音频。
- 原生拒绝会中断旧输出，用独立 TTS 合成替代文字，最多等待 10 秒；失败明确只显示文字。打断、空转写与跨句 caption 状态有回归覆盖，不能复用旧音频充当替代回复。
- 普通响应、SSE done 与原生过滤后的 turn_done 可携带 `content_filtered`。被拦截的轮次保留原会话记录和实际安全回复，不提取个人画像或长期事实。账号数据删除同时清除调试 prompt 快照。

## 验证与边界

完整 Lite 回归 729 passed（58.61 秒，线程异常警告视为错误）；Web 66，Web/PC 构建通过。受控合成标记覆盖拆 token、工具/任务、普通/SSE/TTS、原生缓冲与替代；未要求真实模型生成有害操作内容。

隔离数据库实际方舟正常回答预防/求助讨论，普通接口返回正确过滤字段；流式文字与最终回复一致，6 段真实豆包 TTS 成功，SQL 保存实际回复。原生默认模型仍为 `1.2.1.1`，实际返回 519,108 字节音频，文字→通话→文字连续性及关系一次提交通过。这些结果验证接线与回归，不等于任意输入的审核准确率。

默认词库只覆盖有限中文/英文风险表达。无法仅凭文字验证 caption 与供应商实际波形的语义一致性，也无法撤回已经批准并播放的安全句子。独立 SDK 的第三方宿主需要自行注入审核策略；图片像素、外部服务保留记录、设备沙箱和生产存储仍按各自计划验收。原始用户转写属于用户数据，删除/导出沿用账号隐私控制。
