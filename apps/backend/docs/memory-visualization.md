# 记忆网络

2026-10-20，路线图 6.5。打开 Web/PC 的“记忆库 → 记忆网络”，点选实体或记忆，可查看关联、原文依据、时间、清晰度与淡化状态。支持话题筛选、关键词开关、缩放、拖动及键盘/列表选择。

`GET /memory/user/{user_id}/graph` 从实际 SQL 记忆索引读取，在 Lite 模式也可使用。默认最近 40 条，`limit` 为 1–80；`query` 最长 120 字，按原文或实体文字筛选，SQL 通配符按字面处理。`include_dormant` 和 `include_keywords` 默认 false。端点使用参考宿主的账号归属和待清理屏障，不开放任意 Cypher。

响应包含 nodes、edges、memory_count、truncated、source=sql_index。节点分 memory/entity/keyword；关系附原文 memory_ids。原文投影最多 2,000 字并明确标注截断，不读取向量。最多 80 个记忆节点、60 个实体/关键词、400 条提及与 100 条实体关系；超过范围返回 truncated，界面提示缩小范围。仅已显示且属于该用户的实际记忆可提供关系依据，孤立索引和其他用户数据不进入视图。

自动关键词使用虚线且默认关闭，避免把字面关联显示为明确事实。提取关系可能有误，界面提供原文供核对。查看不会增加访问次数、恢复淡化或改写记忆。删除原文会移除其关联；切换账号、关闭视图会取消请求并清空内容，迟到响应不能恢复旧图。

已用隔离 SQLite 与合成记忆进行实际浏览器验证：3 条记忆/7 个实体、点选西湖的两条依据、关键词开关、空话题、清空后刷新仍为空，桌面和 390px 布局通过。SQL 回归覆盖归属、删除、淡化/过期、只读行为、查询与尺寸边界。Neo4j 实例联调仍属于 2.3，不由此视图替代。
