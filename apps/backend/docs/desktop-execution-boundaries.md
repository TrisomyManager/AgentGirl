# 桌面执行与通知边界

2026-10-20，路线图 7.1/5.4。此版本限制内置工具接收的命令和参数，不是隔离同一操作系统账号下恶意程序或任意 Python 插件的 OS 沙箱。

## 本机工具

Electron 主进程为自己启动的 Python 工具服务生成随机密钥，使用随机 loopback 端口。密钥只通过子进程环境传递，服务启动后移出环境，不写日志、URL、磁盘或渲染页面。子进程不继承云密钥等无关环境变量，退出应用会关闭子进程。

所有工具请求均检查 Bearer 密钥、准确 Host、Origin 和浏览器来源头；没有通配 CORS，跨站预检拒绝。请求最长 64 KiB，结果最长 1 MiB，读取/网络/子进程均有上限。Electron 开启 renderer sandbox，IPC 仅接受当前主窗口主 frame，阻止导航和弹出外部页面。

默认只有系统状态、通知和经确认的公开 HTTP/HTTPS 地址。剪贴板、文件、进程列表、屏幕截图默认不开放；任意程序启动、shell 和未实现音量控制始终不可执行。可选能力由本机宿主环境 `XIAONUAN_TOOL_CAPABILITIES` 明确列出，网络请求和模型参数不能修改授权。

文件能力还要求 `XIAONUAN_SANDBOX_ROOT` 指向既有专用绝对目录。检查真实父子关系、根目录身份、路径穿越、Windows 设备路径/替代数据流、符号链接、junction、reparse point 与硬链接。根目录不能是磁盘根或整个主目录。读取最多 50 KB UTF-8，目录最多显示 100 项；写入最多 50 KB，只能原子新建 txt/md/json/csv/tsv，不覆盖现有文件或生成可执行脚本。

敏感能力和打开地址逐次调用本机确认对话框，默认选取消，始终先显示目标文件/地址。浏览器或工具参数不能伪造 approved；仅持有私有宿主密钥的主进程在确认后提交该字段。通知和剪贴板中的文字经 JSON 数据输入固定 PowerShell 程序，不拼接为命令源码。其他内置子进程不使用 shell=True。

## 远程设备链路

远程只暴露 ping/show_notification/open_url/get_device_status，不再广告尚未实现的远程文件或 shell 能力。服务端复核账号、设备能力、参数结构/尺寸和地址；本机再次检查能力。地址禁止凭据、局域网字面 IP、回环、模糊数值形式、控制字符和非 HTTP 协议；DNS 名称并非网络隔离保证，浏览器仍可能跟随站点跳转。

命令先保存可认领回执再推送，避免快速客户端完成后被覆盖回 delivered。认领和开始执行使用原子状态转换，重复传输不会产生第二个执行者。WebSocket 先认领；轮询解开实际 command 响应，作为断线补充。执行排队有界，等待本机确认后再向服务端核对取消/到期状态。未知结果不自动重放。参考宿主仍是单进程，生产分布式设备存储另行验收。

## Windows 原生通知

提醒/主动消息经已有推送去重后交给原生后台通知接口，由主进程根据真实窗口状态决定是否显示；前台仍使用界面提示。设定应用 ID，点击可激活主窗口，退出关闭活动通知。手工设备通知和提醒共用原生实现，只有系统 show 事件才返回成功，失败/超时明确返回未显示。
