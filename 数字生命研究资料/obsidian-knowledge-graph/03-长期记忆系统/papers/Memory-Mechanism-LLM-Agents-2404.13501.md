# A Survey on the Memory Mechanism of Large Language Model based Agents

> **arXiv**: [2404.13501](https://arxiv.org/abs/2404.13501)
> **年份**: 2024 | **作者**: ACM TOIS 2025接收 | **收录**: ACM TOIS 2025

## 核心贡献

首个LLM Agent记忆机制系统综述。覆盖记忆来源(对话/工具/环境)、形式(文本/向量/结构化)、操作(写入/读取/管理)和评估方法。包含对话Agent和角色扮演Agent记忆应用。

## 对项目的适用性

极高——为项目记忆系统的操作语义(抽取到存储到检索到更新到遗忘)提供完整参考框架。
