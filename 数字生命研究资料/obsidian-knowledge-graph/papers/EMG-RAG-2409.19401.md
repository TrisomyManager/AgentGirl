# Crafting Personalized Agents through RAG on Editable Memory Graphs

> **arXiv**: [2409.19401](https://arxiv.org/abs/2409.19401)
> **年份**: 2024 | **作者**:  | **收录**: EMNLP 2024

## 核心贡献

提出EMG-RAG：可编辑记忆图谱(Editable Memory Graph)+RAG，从用户的智能手机记忆中构建个性化Agent。支持记忆的手动编辑和自动冲突解决。

## 对项目的适用性

高——记忆图谱+可编辑性+冲突解决三重机制直接对应项目记忆系统的核心需求。
